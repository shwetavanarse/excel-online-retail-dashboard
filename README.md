# 📊 Online Retail Sales Dashboard (Excel)
Excel bases retail sales analysis project with cleaned data, pivot tables, dashboard, insights and business recommendations.

## Project Overview

This project is an interactive Online Retail Sales Dashboard developed in Microsoft Excel to analyze sales performance and generate business insights from retail transaction data.

The dashboard allows users to filter data dynamically using slicers and visualize key performance indicators (KPIs), sales trends, and country-wise revenue.

## Business Insights

- Total Revenue generated: **$10.6M**
- Total Invoices: **19,960**
- Average Invoice Value: **$533.17**
- Median Invoice Value: **$303.30**
- Operations across **38 countries**
- Domestic market contributes the majority of revenue.
- High Sales category generates the highest revenue.
- Monthly revenue peaked during October before declining in November.
